Este projeto de sistemas embarcados para o microcontrolador 8051 consiste em um controlador de motor de corrente contínua com monitoramento de rotações integrado. O código foi desenvolvido por, eu, Lucas Garcia Pereira e Alexsandra Pavani Xavier como entrega final de projeto. A arquitetura do software utiliza o Timer 1 configurado no Modo 1 de 16 bits atuando como um contador externo para registrar os pulsos de rotação do motor. O sistema é regido por uma lógica de interrupção que dispara o reset do contador sempre que o limite de dez voltas é atingido, garantindo um ciclo de operação contínuo e preciso, essa contagem é feita usando a flag do timer que é atingida quando todos os bits, dos 16, são iguais a 1, aproveitamos essa flag para implementar a lógica de reset, com o EA (interrupção global) ativo, a compilação é encaminhada para o endereço 001Bh reservada a interrupção do Timer 1 que terá a função de reset do contador.

O funcionamento lógico baseia-se na leitura constante do pino P2.0 para definir a direção do motor. Caso o sistema identifique uma mudança no estado deste pino em comparação à flag de memória F0, ele executa automaticamente uma subrotina de reset para reiniciar a contagem, assegurando que o contador reflita apenas o movimento atual. As saídas de controle para a ponte H do motor são manipuladas pelos pinos P3.0 e P3.1, que alternam entre os estados alto e baixo para inverter a polaridade do motor conforme o sentido selecionado.

Para a interface com o usuário, o programa utiliza um display de sete segmentos do tipo anodo comum conectado às portas P1. A atualização visual ocorre através de uma subrotina que subtrai o valor atual do registrador TL1 do valor de carga inicial para obter um índice decimal de zero a nove. Este índice é usado para buscar o padrão de bits correto em uma tabela de conversão armazenada na memória de programa. Adicionalmente, o ponto decimal do display é controlado dinamicamente para servir como indicador visual de direção, permanecendo aceso no sentido anti-horário e apagado no sentido horário.
